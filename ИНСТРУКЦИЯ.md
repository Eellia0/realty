# Инструкция по сайту «Новый адрес»

Сайт продажи недвижимости на Северном Кипре. Здесь описано, как сайт устроен, как его запускать, как работать с админкой и базой данных и что делать, если что-то пошло не так.

Чтобы читать этот файл в VS Code с оформлением, откройте его и нажмите `Ctrl+Shift+V`.

---

## 1. Как всё устроено

```
Браузер посетителя
      │
      ▼
Сайт на Next.js  ──────►  Яндекс Карты (карта и поиск адресов)
(страницы, админка,
 проверка прав)
      │                    Папка uploads (фотографии объектов)
      ▼
Prisma (переводчик между кодом и базой)
      │
      ▼
PostgreSQL, база realty (объекты, пользователи, избранное, заявки)
```

| Часть | Что делает |
|---|---|
| **Next.js** | Это и сайт, и сервер. Показывает страницы, принимает формы, проверяет, кто вошёл. |
| **Prisma** | Библиотека, через которую код читает и пишет в базу. Структура таблиц описана в одном файле: `prisma/schema.prisma`. |
| **PostgreSQL** | База данных. Установлена у вас на компьютере, база называется `realty`. |
| **Яндекс Карты** | Карта на главной, в каталоге и на странице объекта. В админке через них ставится метка объекта. |
| **Tailwind CSS** | Стили. Цвета сайта заданы в начале файла `src/app/globals.css`. |

### Где что лежит

| Папка или файл | Что внутри |
|---|---|
| `.env` | Пароли и ключи: подключение к базе, ключ шифрования, ключ Яндекс Карт. **Никому не показывать и не публиковать.** |
| `prisma/schema.prisma` | Структура базы данных: какие таблицы и поля есть. |
| `prisma/seed.ts` | Демо-объекты, которые добавляются в пустую базу. |
| `scripts/admin.ts` | Консольная команда для управления администратором. |
| `src/app/` | Страницы сайта. Каждая папка соответствует адресу: `catalog` для `/catalog`, `admin` для `/admin` и так далее. |
| `src/actions/` | Действия на сервере: вход, регистрация, избранное, заявки, сохранение объектов. |
| `src/components/` | Части интерфейса: карточки, фильтры, карты, формы админки. |
| `src/lib/constants.ts` | Справочники: типы недвижимости, регионы, отделка, титулы, удобства. |
| `src/lib/site.ts` | Название сайта, валюта, центр карты. |
| `uploads/` | Загруженные фотографии объектов. |

## 2. Запуск сайта

Все команды выполняются в терминале из папки проекта:

```bash
cd D:\dev\realty
```

### Режим разработки

Используйте его, когда меняете код. Страница сама обновляется после сохранения файла.

```bash
npm run dev
```

Сайт откроется на http://localhost:3000. Остановить: `Ctrl+C` в терминале.

### Рабочий режим

Так сайт будет работать на хостинге: быстрее, но после каждого изменения кода нужна пересборка.

```bash
npm run build                 # собрать сайт
npm start -- -p 3100          # запустить на порту 3100
```

Сайт откроется на http://localhost:3100.

> Если изменили код или файл `.env`, а на сайте ничего не поменялось, значит, сайт в рабочем режиме. Остановите его, снова выполните `npm run build` и запустите.

### Как остановить сайт, запущенный в фоне

Если сайт запускался не в вашем терминале и `Ctrl+C` не к чему применить, выполните в PowerShell:

```powershell
Get-NetTCPConnection -LocalPort 3100 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

Для режима разработки замените `3100` на `3000`.

### Первый запуск на новом компьютере

```bash
npm install                   # установить библиотеки
npm run setup                 # создать таблицы и добавить демо-объекты
npm run admin -- create       # создать администратора
npm run dev
```

Перед этим нужно создать базу и заполнить `.env`. Как это сделать, описано в разделе 4.

## 3. Админка

### Вход

1. Откройте `/admin/login`, например http://localhost:3100/admin/login.
2. Введите email и пароль администратора.
3. Введите шесть цифр из Яндекс Ключа или Google Authenticator.

Сеанс администратора длится 12 часов, потом нужно войти заново.

### Добавление объекта

1. В админке нажмите «+ Добавить объект».
2. Заполните поля. Обязательны заголовок, цена, площадь, адрес и метка на карте.
3. Нажмите «Добавить объект».

Как заполнять поля:

| Поле | Как заполнять |
|---|---|
| **Цена** | В фунтах, только число: `185000`. Пробелы можно ставить. |
| **Спальни** | Число спален. `2` на сайте превращается в «2+1», `0` означает студию. |
| **Этаж** | По местной нумерации: первый этаж — это `0`. Под полем видна подсказка, как этаж будет показан посетителям, например «0 (1-й)». |
| **Расстояние до моря** | В метрах: `350`. По нему работает фильтр «До моря». |
| **Статус на сайте** | «Опубликован»: виден всем. «Забронирован»: виден с пометкой. «Продан» и «Черновик»: скрыты из каталога. |
| **Метка на карте** | Когда вы заполнили адрес и перешли к следующему полю, метка ставится сама. Её можно перетащить мышкой в точное место или поставить кликом по карте. |
| **Фотографии** | Перетащите файлы в рамку или нажмите на неё. Подходят JPG, PNG и WEBP до 10 МБ. Первое фото становится обложкой, порядок меняется стрелками. |

> Автоматическая метка по адресу работает только с ключом Яндекс Карт. Без ключа ставьте метку кликом по карте. Как получить ключ, описано в разделе 5.

### Редактирование и удаление

В списке объектов есть кнопки «Изменить», «На сайте» и «Удалить». Вкладки над списком фильтруют объекты по статусу. Удаление нельзя отменить, поэтому если объект продан, лучше поставить ему статус «Продан».

### Заявки на просмотр

Раздел «Заявки» показывает, кто и на какой объект оставил телефон. Новые заявки подсвечены, их число видно на кнопке. Статус («Новая», «В работе», «Закрыта») меняется выпадающим списком.

### Безопасность

В разделе «Безопасность» можно:
- **сменить пароль**: понадобятся текущий пароль и код из приложения;
- **завершить другие сеансы**: если входили с чужого компьютера.

### Команды администратора в терминале

Через сайт стать администратором нельзя, только этими командами:

```bash
npm run admin -- create       # создать администратора или сменить ему пароль
npm run admin -- reset-2fa    # сбросить двухфакторную защиту, если потерян телефон
npm run admin -- list         # показать администраторов
```

Email и пароль команда спросит сама, пароль при вводе не отображается. После `reset-2fa` при следующем входе сайт заново покажет QR-код.

## 4. База данных

### Как сайт подключается к базе

Строка подключения лежит в `.env`:

```
DATABASE_URL="postgresql://realty_app:ПАРОЛЬ@localhost:5432/realty?schema=public"
```

| Часть строки | Значение |
|---|---|
| `realty_app` | Пользователь базы, под которым работает сайт. У него есть права только на базу `realty`, к остальным вашим базам он доступа не имеет. |
| `ПАРОЛЬ` | Случайный пароль этого пользователя. Хранится только в `.env`. |
| `localhost:5432` | PostgreSQL на вашем компьютере, стандартный порт. |
| `realty` | Название базы. |

Сайт не использует суперпользователя `postgres`. Даже если кто-то получит доступ к сайту, до ваших других баз он не доберётся.

### Таблицы

| Таблица | Что хранит |
|---|---|
| `Property` | Объекты недвижимости: цена, площадь, адрес, координаты, характеристики. |
| `PropertyImage` | Ссылки на фото объектов и их порядок. Сами файлы лежат в папке `uploads`. |
| `User` | Пользователи и администратор. Пароли хранятся только в виде хэша, узнать пароль из базы нельзя. |
| `Session` | Открытые сеансы входа. |
| `Favorite` | Избранное зарегистрированных пользователей. Избранное гостей хранится в их браузере. |
| `Lead` | Заявки на просмотр. |
| `RateLimit` | Счётчики попыток входа, регистрации и заявок для защиты от подбора пароля и спама. |

### Как посмотреть данные в pgAdmin

1. Подключитесь к серверу `localhost`, порт `5432`, пользователь `postgres` и ваш пароль.
2. Откройте realty, затем Schemas, public и Tables.
3. Если базы `realty` не видно, нажмите правой кнопкой на Databases и выберите Refresh.

В SQL-запросах названия таблиц пишите **в двойных кавычках**, потому что они начинаются с заглавной буквы:

```sql
SELECT id, title, price, status FROM "Property";
SELECT name, phone, "createdAt" FROM "Lead" ORDER BY "createdAt" DESC;
```

Без кавычек PostgreSQL ответит ошибкой `relation "property" does not exist`.

### Prisma Studio: просмотр базы в браузере

```bash
npm run db:studio
```

Откроется http://localhost:5555, где таблицы можно смотреть и редактировать как в Excel.

### Изменение структуры базы

1. Отредактируйте `prisma/schema.prisma`, например добавьте поле.
2. Выполните:

```bash
npm run db:push
```

Prisma сама изменит таблицы в базе. Если изменение удаляет данные, она предупредит и спросит подтверждение.

### Резервная копия и восстановление

Утилиты PostgreSQL не прописаны в PATH, поэтому команды используют полный путь. Пароль `realty_app` возьмите из `.env`.

```powershell
# Сделать копию базы в файл
& "C:\Program Files\PostgreSQL\17\bin\pg_dump.exe" -U realty_app -h localhost -d realty -f backup.sql

# Восстановить из файла в пустую базу
& "C:\Program Files\PostgreSQL\17\bin\psql.exe" -U realty_app -h localhost -d realty -f backup.sql
```

**Фотографии в базе не хранятся.** Вместе с `backup.sql` сохраняйте папку `uploads`.

### Перенос на новый компьютер или хостинг

1. Создайте базу и пользователя под суперпользователем `postgres`:

```sql
CREATE ROLE realty_app LOGIN PASSWORD 'придумайте-длинный-пароль';
CREATE DATABASE realty OWNER realty_app;
```

2. Скопируйте `.env.example` в `.env` и впишите пароль в `DATABASE_URL`.
3. Создайте `APP_SECRET`:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

4. Выполните `npm run setup` для пустой базы или восстановите копию `backup.sql`.

> Если перенести копию базы с новым `APP_SECRET`, двухфакторная защита администратора перестанет работать. Тогда выполните `npm run admin -- reset-2fa` и подключите приложение заново.

## 5. Настройки

### Файл `.env`

| Переменная | Что это |
|---|---|
| `DATABASE_URL` | Подключение к базе, подробно описано в разделе 4. |
| `APP_SECRET` | Ключ шифрования секретов двухфакторной защиты. Если его сменить или потерять, 2FA придётся настроить заново. |
| `NEXT_PUBLIC_YANDEX_MAPS_API_KEY` | Ключ Яндекс Карт. |

После изменения `.env` сайт нужно перезапустить, а в рабочем режиме ещё и пересобрать.

### Ключ Яндекс Карт

Без ключа карта показывается, но поиск адреса в админке не работает.

1. Зайдите на https://developer.tech.yandex.ru под Яндекс-аккаунтом.
2. Подключите сервис «JavaScript API и HTTP Геокодер», бесплатный тариф.
3. Скопируйте ключ и вставьте в `.env`:

```
NEXT_PUBLIC_YANDEX_MAPS_API_KEY="ваш-ключ"
```

4. Пересоберите и перезапустите сайт.
5. Когда у сайта появится домен, в кабинете Яндекса ограничьте ключ этим доменом в поле «HTTP Referer». Ключ виден в коде страницы, и без ограничения им смогут пользоваться чужие сайты.

### Название, валюта, справочники

| Что поменять | Где |
|---|---|
| Название сайта, описание, валюта, центр карты | `src/lib/site.ts` |
| Типы недвижимости, регионы, отделка, мебель, титулы, удобства, варианты фильтра «До моря» | `src/lib/constants.ts` |
| Цвета | начало `src/app/globals.css`, блок `@theme` |

В справочниках слева стоит ключ, который хранится в базе, справа подпись для посетителей. Подписи можно менять свободно. Ключи у существующих объектов менять нельзя, иначе объекты потеряют это значение.

### Как включить аренду

1. В `src/lib/constants.ts` раскомментируйте строку `RENT: "Аренда"`.
2. В форме объекта появится выбор «Продажа» или «Аренда», цена аренды будет показываться как «£…/мес».
3. Каталог уже понимает фильтр `?deal=RENT`. Останется добавить переключатель «Продажа / Аренда» на страницу каталога.

## 6. Что видят посетители

- **Главная.** Поиск по типу, спальням, расстоянию до моря и цене, быстрые ссылки («Первая линия», «Виллы»), новые объекты и общая карта.
- **Каталог.** Два режима: «Списком» по умолчанию и «На карте». В режиме карты справа показаны только объекты из видимой области. При наведении на карточку её метка или кластер на карте становится янтарным. Зум — колёсиком мыши.
- **Фильтры.** Основные видны сразу, остальные (регион, отделка, титул, удобства) открываются по «Ещё фильтры».
- **Избранное.** Работает без регистрации, тогда хранится в браузере. При регистрации или входе всё добавленное переносится в аккаунт.
- **Заявка на просмотр.** Форма на странице объекта. Заявка появляется в админке в разделе «Заявки».

## 7. Безопасность

Что уже сделано:
- **Администратор.** Создаётся только командой в терминале. Регистрация на сайте всегда даёт обычного пользователя.
- **Двухфакторная защита.** Для админки она обязательна, и каждый код подходит только один раз.
- **Подбор пароля.** После 5 неверных попыток для одного email вход блокируется на 15 минут. Регистрация и заявки тоже ограничены по частоте.
- **Пароли.** Хранятся только в виде хэша bcrypt.
- **Проверка прав.** Права администратора проверяются в каждом действии, а не только при открытии страницы.
- **Защита браузера.** Браузер выполняет только скрипты самого сайта и Яндекс Карт. Сайт нельзя встроить в чужую страницу.
- **Загрузка фото.** Файлы проверяются по содержимому, подделанный файл не загрузится.
- **База.** Сайт работает под отдельным пользователем базы с минимальными правами.

Чего делать нельзя:
- Публиковать файл `.env`, пересылать его или выкладывать в git. Он уже исключён из git.
- Показывать кому-либо QR-код и ключ под ним при настройке двухфакторной защиты.

### Перед публикацией сайта в интернете

- [ ] Получить ключ Яндекс Карт и ограничить его доменом сайта.
- [ ] Настроить работу сайта только по HTTPS (обычно это делает хостинг).
- [ ] Сменить пароль суперпользователя PostgreSQL `postgres`: сейчас он простой.
- [ ] Хранить код в приватном репозитории и включить двухфакторную защиту на GitHub или GitLab и на хостинге.
- [ ] Настроить регулярные резервные копии базы и папки `uploads`.
- [ ] Перенести фото в облачное хранилище, если хостинг не сохраняет файлы между перезапусками.

## 8. Частые проблемы

| Проблема | Что делать |
|---|---|
| **Изменения в коде не видны на сайте** | Сайт запущен в рабочем режиме. Пересоберите: `npm run build`, затем перезапустите. |
| **«Слишком много попыток. Попробуйте через N мин.»** | Подождите 15 минут. Если ждать нельзя, выполните в pgAdmin `DELETE FROM "RateLimit";` |
| **Потерян телефон с кодами** | `npm run admin -- reset-2fa`, затем войдите и отсканируйте новый QR-код. |
| **Забыт пароль администратора** | `npm run admin -- create` с тем же email: команда задаст новый пароль. |
| **Код из приложения не подходит** | Проверьте, что время на телефоне выставляется автоматически. Код меняется каждые 30 секунд, вводите свежий. |
| **Карта не показывается** | Проверьте интернет. Если на месте карты текст «Карта временно недоступна», проверьте ключ Яндекс Карт в `.env`. |
| **Поиск адреса в админке не работает** | Нужен ключ Яндекс Карт. Пока его нет, ставьте метку кликом по карте. |
| **`port 3100 is already in use`** | Сайт уже запущен. Остановите его командой из раздела 2 или откройте уже работающий. |
| **pgAdmin: `relation "property" does not exist`** | Названия таблиц пишите в кавычках: `"Property"`. |
| **Сайт не подключается к базе** | Проверьте, что служба PostgreSQL запущена: «Службы Windows», служба `postgresql-x64-17`. |
