# Инструкция по сайту «Новый адрес»

Сайт продажи недвижимости на Северном Кипре, на русском и английском. Здесь описано, как сайт устроен, как его запускать, как работать с админкой, базой данных и GitHub и что делать, если что-то пошло не так.

Чтобы читать этот файл в VS Code с оформлением, откройте его и нажмите `Ctrl+Shift+V`.

---

## 1. Как всё устроено

```
Браузер посетителя
      │
      ▼
Сайт на Next.js  ──────►  Яндекс Карты (карта и поиск адресов)
(страницы, админка,  ───►  ЦБ РФ (курсы валют)
 проверка прав)      ───►  Telegram и почта (уведомления о заявках, письма)
      │
      │                    Папка uploads (фото и планировки)
      ▼
Prisma (переводчик между кодом и базой)
      │
      ▼
PostgreSQL, база realty (объекты, пользователи, избранное, заявки, настройки)
```

| Часть | Что делает |
|---|---|
| **Next.js** | Это и сайт, и сервер. Показывает страницы, принимает формы, проверяет, кто вошёл. |
| **Prisma** | Библиотека, через которую код работает с базой. Структура таблиц описана в `prisma/schema.prisma`. |
| **PostgreSQL** | База данных на вашем компьютере, называется `realty`. |
| **Яндекс Карты** | Карта на главной, в каталоге и на странице объекта, выбор точки в админке. |
| **Tailwind CSS** | Стили. Цвета сайта заданы в начале `src/app/globals.css`. |

### Где что лежит

| Папка или файл | Что внутри |
|---|---|
| `.env` | Пароли и ключи. **Никому не показывать и не публиковать.** |
| `prisma/schema.prisma` | Структура базы данных. |
| `prisma/seed.ts`, `prisma/demo-en.json` | Демо-объекты и их английские тексты. |
| `scripts/` | Консольные команды: администратор, Telegram, резервные копии. |
| `src/app/` | Страницы сайта. Папка соответствует адресу: `catalog` — это `/catalog`. |
| `src/actions/` | Действия на сервере: вход, заявки, сохранение объектов, настройки. |
| `src/components/` | Части интерфейса. |
| `src/i18n/messages/` | Все тексты сайта: `ru.ts` — русские, `en.ts` — английские. |
| `src/lib/constants.ts` | Справочники: типы недвижимости, регионы, отделка, удобства. |
| `uploads/` | Загруженные фото и планировки. В git не попадают. |
| `backups/` | Резервные копии. В git не попадают. |

## 2. Запуск сайта

Все команды выполняются в терминале из папки проекта:

```bash
cd D:\dev\realty
```

### Режим разработки

Для правки кода. Страница сама обновляется после сохранения файла.

```bash
npm run dev
```

Сайт откроется на http://localhost:3000. Остановить: `Ctrl+C`.

### Рабочий режим

Так сайт будет работать на хостинге. После каждого изменения кода или `.env` нужна пересборка.

```bash
npm run build                 # собрать сайт
npm start -- -p 3100          # запустить на порту 3100
```

### Как остановить сайт, запущенный в фоне

```powershell
Get-NetTCPConnection -LocalPort 3100 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

### Первый запуск на новом компьютере

```bash
npm install                   # установить библиотеки
npm run setup                 # создать таблицы и добавить демо-объекты
npm run admin -- create       # создать администратора
npm run dev
```

Перед этим нужно создать базу и заполнить `.env` (раздел 5).

## 3. Админка

### Вход

1. Откройте `/admin/login`, например http://localhost:3100/admin/login.
2. Введите email и пароль администратора.
3. Введите шесть цифр из приложения для кодов (Яндекс Ключ, Google Authenticator).

Сеанс администратора длится 12 часов. Админка только на русском.

### Добавление объекта

«+ Добавить объект», заполнить поля, «Добавить объект». Обязательны заголовок, цена, площадь, адрес и метка на карте.

| Поле | Как заполнять |
|---|---|
| **Цена** | В фунтах, только число: `185000`. На сайте посетитель может переключить валюту. |
| **Спальни** | Число спален. `2` на сайте превращается в «2+1», `0` — студия. |
| **Этаж** | По местной нумерации: первый этаж — это `0`. Под полем видно, как этаж покажется посетителям. |
| **Рассрочка** | Галочка «Продаётся в рассрочку» открывает поля: первый взнос в %, срок в месяцах, ставка (0 — без процентов) и условия. Рядом сразу виден расчёт платежа. |
| **Расстояние до моря** | В метрах. По нему работает фильтр «До моря». |
| **Расстояния до важных мест** | До аэропортов Эрджан и Ларнаки и до городов считаются сами по метке. Свои места («Школа — 800 м») можно добавить кнопкой «+ Добавить место». |
| **Английская версия** | Необязательно: заголовок, описание, посёлок, адрес и условия рассрочки по-английски. Пустое поле — на английском сайте покажется русский текст. |
| **Метка на карте** | Ставится сама, когда вы заполнили адрес и перешли к следующему полю (нужен ключ Яндекс Карт). Можно поставить кликом и перетащить. |
| **Фотографии** | JPG, PNG или WEBP до 20 МБ. Сжимаются автоматически, данные камеры и GPS удаляются. Первое фото — обложка. |
| **Планировки и видео** | Необязательно. Видео — ссылка на YouTube, RuTube или VK Видео. Если планировок или видео нет, блоков на странице объекта не будет. |
| **Статус** | «Опубликован» виден всем, «Забронирован» — с пометкой, «Продан» и «Черновик» скрыты из каталога. |

Удалённые из объекта фото и фото удалённых объектов стираются с диска автоматически.

### Заявки

Раздел «Заявки»: кто, когда и на какой объект оставил телефон. Общие заявки со страницы «Контакты» помечены «Общая заявка: подбор». Пометка **EN** — клиент писал с английской версии, отвечать лучше по-английски. Статус меняется выпадающим списком.

### Настройки

Раздел «Настройки»:
- **Контакты на сайте:** телефон, WhatsApp, Telegram, почта, адрес и часы работы (и их английские варианты). Показываются в шапке, подвале, на странице «Контакты» и у каждого объекта. Пустые поля не показываются.
- **Почта для заявок** и **кто обрабатывает данные** (для политики конфиденциальности).
- **Уведомления о заявках:** состояние Telegram и почты, кнопки «Отправить проверку» и пошаговые подсказки.

### Безопасность

Раздел «Безопасность»: смена пароля (нужен код из приложения) и завершение других сеансов.

### Команды администратора

```bash
npm run admin -- create       # создать администратора или сменить пароль
npm run admin -- reset-2fa    # сбросить двухфакторную защиту, если потерян телефон
npm run admin -- list         # показать администраторов
```

## 4. Уведомления и почта

### Telegram

1. В Telegram откройте @BotFather, отправьте `/newbot`, придумайте имя.
2. Скопируйте токен в `.env`: `TELEGRAM_BOT_TOKEN="..."`.
3. Напишите своему боту любое сообщение (или добавьте бота в рабочую группу и напишите там).
4. Выполните `npm run telegram -- chat-id` и скопируйте номер в `TELEGRAM_CHAT_ID`.
5. Пересоберите и перезапустите сайт, в «Настройках» нажмите «Отправить проверку».

### Почта (Яндекс)

Нужна для писем о заявках и для восстановления пароля пользователей.

1. id.yandex.ru → «Безопасность» → «Пароли приложений» → создать пароль для «Почты».
2. В `.env`: `SMTP_HOST="smtp.yandex.ru"`, `SMTP_PORT="465"`, `SMTP_USER` и `MAIL_FROM` — ваш адрес, `SMTP_PASS` — пароль приложения.
3. В «Настройках» укажите «Почту для заявок», пересоберите сайт и нажмите «Отправить проверку».

### Восстановление пароля

Пользователь нажимает «Забыли пароль?» и получает письмо со ссылкой на 1 час. Для администратора восстановление по почте отключено: только `npm run admin -- create`.

## 5. База данных

### Подключение

Строка в `.env`:

```
DATABASE_URL="postgresql://realty_app:ПАРОЛЬ@localhost:5432/realty?schema=public"
```

Сайт работает под пользователем `realty_app`, у которого есть права только на базу `realty`.

### Таблицы

| Таблица | Что хранит |
|---|---|
| `Property` | Объекты: цена, площадь, адрес, координаты, характеристики, рассрочка, английские тексты. |
| `PropertyImage` | Фото и планировки объектов (ссылки на файлы и порядок). |
| `User`, `Session` | Пользователи и сеансы входа. Пароли — только хэш. |
| `Favorite` | Избранное зарегистрированных пользователей. |
| `Lead` | Заявки: имя, телефон, объект, язык сайта, отметка о согласии. |
| `SiteSettings` | Контакты и настройки из админки. |
| `CurrencyRates` | Последний известный курс валют ЦБ РФ. |
| `PasswordReset` | Одноразовые ссылки восстановления пароля. |
| `RateLimit` | Счётчики попыток входа и заявок (защита от подбора и спама). |

### Просмотр данных

- **pgAdmin:** сервер `localhost`, база `realty`, Schemas → public → Tables. В SQL имена таблиц в кавычках: `SELECT * FROM "Property";`
- **Prisma Studio:** `npm run db:studio`, откроется http://localhost:5555.

### Изменение структуры

Отредактируйте `prisma/schema.prisma` и выполните `npm run db:push`.

### Создание базы на новом компьютере

```sql
CREATE ROLE realty_app LOGIN PASSWORD 'придумайте-длинный-пароль';
CREATE DATABASE realty OWNER realty_app;
```

Затем скопируйте `.env.example` в `.env`, впишите пароль и создайте `APP_SECRET`:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## 6. Резервные копии

### Автоматически

В планировщике Windows настроена задача **Realty backup**: каждый день в 3:00 (если компьютер был выключен — при следующем включении). Копии лежат в `D:\dev\realty\backups`, хранятся последние 14. Журнал — `backups\backup.log`.

Вручную:

```bash
npm run backup
```

Каждая копия — папка с датой: `db.dump` (база) и `uploads` (фото).

Чтобы копии сразу уходили в облако, укажите в `.env` папку, которая синхронизируется (например, Яндекс Диск): `BACKUP_DIR="D:\YandexDisk\realty-backups"`.

Убрать задачу из планировщика:

```powershell
Unregister-ScheduledTask -TaskName "Realty backup" -Confirm:$false
```

### Восстановление

```powershell
# 1. База: восстановить копию в базу realty (текущие данные будут заменены)
& "C:\Program Files\PostgreSQL\17\bin\pg_restore.exe" -U realty_app -h localhost -d realty --clean --if-exists --no-owner "D:\dev\realty\backups\2026-10-15_03-00\db.dump"

# 2. Фото: скопировать папку uploads из копии в D:\dev\realty\uploads
```

Пароль `realty_app` — в `.env`.

## 8. Настройки сайта (`.env`)

| Переменная | Что это |
|---|---|
| `DATABASE_URL` | Подключение к базе. |
| `APP_SECRET` | Ключ шифрования секретов 2FA. Если сменить — 2FA придётся настроить заново. |
| `SITE_URL` | Адрес сайта без слэша в конце. Из него строятся ссылки в письмах и уведомлениях. На хостинге — `https://ваш-домен`. |
| `NEXT_PUBLIC_YANDEX_MAPS_API_KEY` | Ключ Яндекс Карт. |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Уведомления в Telegram. |
| `SMTP_*`, `MAIL_FROM` | Почта. |
| `BACKUP_DIR`, `BACKUP_KEEP` | Куда класть резервные копии и сколько хранить (необязательно). |

После изменения `.env` сайт нужно пересобрать и перезапустить.

### Ключ Яндекс Карт

1. https://developer.tech.yandex.ru → подключить «JavaScript API и HTTP Геокодер».
2. Вставить ключ в `NEXT_PUBLIC_YANDEX_MAPS_API_KEY`.
3. Когда появится домен, ограничить ключ этим доменом в поле «HTTP Referer».

## 9. Что видят посетители

- **Два языка.** Русский на обычных адресах, английский на `/en/…`. Переключатель «RU / EN» в шапке.
- **Валюты.** Переключатель «£ € ₽». Цена в фунтах точная, евро и рубли — по курсу ЦБ РФ (обновляется раз в 3 часа).
- **Каталог.** Списком или на карте. Фильтры по типу, спальням, цене, морю, региону, отделке, титулу, рассрочке и удобствам.
- **Страница объекта.** Фото, характеристики, рассрочка, планировки, видео, расстояния, карта, кнопки WhatsApp/Telegram/звонка и запись на просмотр.
- **Избранное.** Работает без регистрации, при входе переносится в аккаунт.
- **Превью ссылок.** При пересылке ссылки в мессенджер появляется картинка с фото, ценой и характеристиками. Работает, когда сайт открыт из интернета по настоящему адресу.

## 10. Безопасность

- Администратор создаётся только командой; вход в админку — пароль плюс код из приложения.
- После 5 неверных паролей для одного email вход блокируется на 15 минут; регистрация, заявки и восстановление пароля тоже ограничены.
- Пароли — только хэш bcrypt; сеансы — хэш в базе.
- Браузер выполняет только скрипты сайта и Яндекс Карт; видео — только с YouTube, RuTube и VK.
- Загружаемые фото проверяются по содержимому и перекодируются.
- Сайт работает с базой под отдельным пользователем с минимальными правами.

### Перед публикацией в интернете

- [ ] Ключ Яндекс Карт, ограниченный доменом сайта.
- [ ] Только HTTPS (обычно делает хостинг); `SITE_URL` с вашим доменом.
- [ ] Сменить пароль суперпользователя PostgreSQL `postgres`.
- [ ] Подключить Telegram и почту.
- [ ] Показать юристу политику конфиденциальности.
- [ ] Настроить резервные копии на сервере хостинга (та же команда `npm run backup` по расписанию).
- [ ] Перенести фото в облачное хранилище, если хостинг не сохраняет файлы между перезапусками.

## 11. Частые проблемы

| Проблема | Что делать |
|---|---|
| **Изменения не видны на сайте** | Сайт в рабочем режиме: `npm run build`, затем перезапуск. |
| **«Слишком много попыток…»** | Подождать 15 минут или выполнить в pgAdmin `DELETE FROM "RateLimit";` |
| **Потерян телефон с кодами** | `npm run admin -- reset-2fa`, затем войти и отсканировать новый QR-код. |
| **Забыт пароль администратора** | `npm run admin -- create` с тем же email. |
| **Не приходят уведомления** | «Настройки» → «Отправить проверку». Сообщение подскажет, чего не хватает в `.env`. |
| **Курсы не обновляются** | Сайт показывает последний сохранённый курс. Если его нет — цены только в фунтах. Проверьте интернет. |
| **Поиск адреса в админке не работает** | Нужен ключ Яндекс Карт; пока его нет — ставьте метку кликом по карте. |
| **pgAdmin: `relation "property" does not exist`** | Имена таблиц в кавычках: `"Property"`. |
| **Сайт не подключается к базе** | Проверьте службу `postgresql-x64-17` в «Службах Windows». |
