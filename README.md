# Новый адрес: недвижимость на Северном Кипре

Next.js 16, TypeScript, Tailwind CSS 4, Prisma, PostgreSQL, Яндекс Карты.

Подробная инструкция по запуску, админке, базе данных и решению проблем лежит в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Запуск

```bash
npm install
npm run setup                 # таблицы и 10 демо-объектов
npm run admin -- create       # создать администратора (email и пароль спросит)
npm run dev                   # http://localhost:3000
```

Вход в админку: `/admin/login`. При первом входе нужно подключить приложение для одноразовых кодов.

## Настройки в `.env`

| Переменная | Что это |
|---|---|
| `DATABASE_URL` | Подключение под ролью `realty_app`, у которой есть права только на базу `realty` |
| `APP_SECRET` | Ключ шифрования секретов 2FA. Если его сменить, 2FA придётся настроить заново |
| `NEXT_PUBLIC_YANDEX_MAPS_API_KEY` | Ключ JavaScript API Яндекс Карт. Без него карта работает, а поиск по адресу нет |

Файл `.env` не попадает в git. Шаблон лежит в `.env.example`.

## Безопасность

- **Администратор** создаётся только командой на сервере. Через регистрацию на сайте стать администратором нельзя.
- **Двухфакторная защита** обязательна для админки. Без неё открывается только страница настройки 2FA. Каждый код принимается один раз.
- **Лимиты попыток.** Вход: 5 неудач на email и 30 на IP за 15 минут. Регистрация: 5 в час с IP. Заявки: 5 за 10 минут с IP.
- **Пароли** хэшируются bcrypt с cost 12. Время ответа не выдаёт, существует ли email.
- **Сессии** хранятся в БД в виде хэша. Сессия администратора живёт 12 часов. Смена пароля и включение 2FA завершают остальные сеансы.
- **Права проверяются в каждом действии и API**, а не только при открытии страницы.
- **Content-Security-Policy** с nonce разрешает только скрипты сайта и Яндекс Карт. Дополнительно включены X-Frame-Options, HSTS, nosniff и Referrer-Policy.
- **Загрузка фото** проверяет содержимое файла, а не заявленный тип. Файлы получают случайные имена и отдаются с запретом исполнения.
- **База.** Сайт подключается под отдельной ролью без прав суперпользователя.

Команды администратора:

```bash
npm run admin -- create       # новый администратор или смена пароля
npm run admin -- reset-2fa    # потерян телефон с кодами
npm run admin -- list
```

## Особенности Северного Кипра

- Цены в фунтах стерлингов. Валюта задаётся в `src/lib/site.ts`.
- Спальни показываются в местном формате: 2 значит «2+1», 0 значит студия.
- Этаж хранится по местной нумерации, где первый этаж нулевой. На сайте рядом указан привычный номер, например «0 (1-й)».
- Справочники типов, регионов, титулов, отделки и удобств лежат в `src/lib/constants.ts`.

## Как включить аренду

1. Раскомментировать `RENT` в `src/lib/constants.ts`.
2. В админке появится выбор типа сделки, цена для аренды будет показываться в формате «£/мес».
3. Каталог уже фильтрует по `?deal=RENT`. Останется добавить переключатель в каталог.

## Перед публикацией в интернете

- Получить ключ Яндекс Карт и ограничить его своим доменом в кабинете разработчика.
- Сайт должен работать только по HTTPS.
- Сменить пароль суперпользователя PostgreSQL `postgres`.
- Хранить код в приватном репозитории с включённой 2FA на GitHub или GitLab и на хостинге.
- Делать резервные копии: `pg_dump -U realty_app -d realty > backup.sql`.
