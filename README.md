# Новый адрес: недвижимость на Северном Кипре

Сайт продажи недвижимости на русском и английском. Next.js 16, TypeScript, Tailwind CSS 4, Prisma, PostgreSQL, Яндекс Карты.

Подробная инструкция по запуску, админке, базе данных, уведомлениям, резервным копиям и решению проблем — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Быстрый старт

```bash
npm install
cp .env.example .env          # заполнить DATABASE_URL, APP_SECRET, SITE_URL
npm run setup                 # таблицы и 10 демо-объектов
npm run admin -- create       # создать администратора
npm run dev                   # http://localhost:3000, английская версия — /en
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Режим разработки |
| `npm run build` / `npm start` | Сборка и рабочий режим |
| `npm run db:push` | Применить изменения `prisma/schema.prisma` к базе |
| `npm run db:studio` | Просмотр базы в браузере |
| `npm run admin -- create \| reset-2fa \| list` | Управление администратором |
| `npm run telegram -- chat-id` | Узнать номер чата для уведомлений |
| `npm run backup` | Резервная копия базы и фото |

## Что умеет

- Каталог списком и на карте, фильтры по морю, региону, отделке, титулу, рассрочке и удобствам.
- Страница объекта: фото, планировки, видео, рассрочка, расстояния до важных мест, кнопки мессенджеров, запись на просмотр.
- Избранное без регистрации с переносом в аккаунт, восстановление пароля по почте.
- Переключатель валют (£ € ₽ по курсу ЦБ РФ) и языков (RU / EN).
- Админка: объекты, заявки с уведомлениями в Telegram и на почту, настройки контактов, двухфакторная защита.
- SEO: понятные адреса, карта сайта, hreflang, превью ссылок для мессенджеров.
